# Rewritten Draft

Психологический хоррор в формате визуальной новеллы. Демо: пролог и первая глава.

## О чём

Женя и Рина живут вдвоём в тесной квартире в большом городе. Одна комната, один плед,
чай на двоих, окно во двор-колодец. Снаружи шумно и чужо, внутри — тепло.

Проблема одна: игры не было. Есть черновик — текст, который Рина пишет заново,
реплика за репликой. Ты играешь Женю, но каждый выбор — это её догадка о том,
что он бы сделал.

Хоррор здесь не в монстрах, а в нежности: чем теплее сцена, тем страшнее трещина под ней.

## Статус

Демо: пролог + глава 1 (~10–15 минут). Дальше — главы 2–5, три концовки и мета-механики
(память между прохождениями, заметки на полях, подмена бэкапа).

## Как запустить

Нужен Ren'Py 8.5.3 или новее — https://www.renpy.org/latest.html

1. Распаковать SDK.
2. Положить папку проекта рядом с SDK (или в любом удобном месте).
3. Запустить Ren'Py, выбрать проект в списке и нажать Launch.

Из терминала:

```
renpy.exe путь/к/rewritten-draft
```

## Структура

```
game/
  script.rpy        — сценарий: пролог и глава 1
  options.rpy       — название, версия, язык
  gui.rpy           — палитра и вёрстка интерфейса
  screens.rpy       — экраны Ren'Py
  tl/russian/       — русская локализация интерфейса
docs/
  story.md          — сюжетная библия: персонажи, главы, концовки
  script_draft.rpy  — рабочая версия сценария
```
